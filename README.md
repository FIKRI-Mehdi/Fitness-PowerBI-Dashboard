🏋️‍♂️ **Fitness Dashboard – Power BI Project**

![Fitness_dashboard](https://github.com/FIKRI-Mehdi/Fitness-PowerBI-Dashboard/blob/main/Fitness_dashboard.png)

📖 **Overview**

The Fitness Dashboard is an interactive analytics report built with Power BI, designed to provide a complete overview of a gym’s performance. It visualizes key insights related to financial performance, client memberships, and monthly trends, helping fitness center managers make data-driven decisions effortlessly.

This project demonstrates how data visualization and business intelligence can transform raw operational data into meaningful insights through a clear and modern design.

🎯 **Project Objectives**

Provide an at-a-glance view of gym performance and profitability.

Analyze revenues, expenses, and profits over time.

Monitor membership status (active vs expired) across different tiers.

Identify monthly trends and key business periods.

Track individual client progress and membership engagement.

📊 **Key Features**

💰 Financial Performance

Visual breakdown of Revenue, Expenses, and Profit.

Monthly trend analysis to identify best-performing periods.

🧍‍♂️ Membership Analytics

Active vs. expired members displayed by Platinum, Gold, and Silver tiers.

Easy-to-read progress bars showing individual client membership completion.

📅 Operational Summary

Total clients, trainers, and key financial KPIs at a glance.

Monthly member trend chart to identify high and low subscription periods.

🧩 Tools & Techniques

Power BI Desktop – dashboard creation and data modeling

DAX (Data Analysis Expressions) – for KPIs and calculated measures

Data Visualization Best Practices – for clean and effective storytelling

Dark UI Theme – to highlight metrics and create visual contrast

💡 **Insights**

This dashboard highlights how even small or medium-sized gyms can leverage data analytics to improve their operations, client retention, and financial planning.
It reflects the importance of data storytelling, merging analytical accuracy with intuitive design.
